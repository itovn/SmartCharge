# Trang SmartCharge (nhánh gh-pages của itovn/SmartCharge)

Trang giới thiệu và nguồn Cydia của [SmartCharge](https://github.com/itovn/SmartCharge) — giữ mức sạc, pin nghỉ khi cắm sạc, lịch
xả pin cho iPad / iPhone iOS 6 đã jailbreak.

- Trang: https://itovn.github.io/SmartCharge/ (English: https://itovn.github.io/SmartCharge/en.html)
- Nguồn Cydia: `https://itovn.github.io/SmartCharge/cydia/` — tạo bằng `tools/update-cydia-repo.sh` + `tools/sign-cydia-repo.sh`
  của repo SmartCharge (`Release.gpg` + `InRelease`, khoá công khai `cydia/vn.smartcharge.gpg`).
- Hỏi đáp, báo lỗi: nhóm Telegram https://t.me/tivikit

Trang viết cho Safari iOS 5 / 6 (không biến CSS, flex, grid; dải màu có tiền tố `-webkit-`).
